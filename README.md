# WhyA Chat (Supabase only)

Tidak memakai Firebase.

## Setup
1. Supabase SQL Editor → jalankan:
   - `supabase/schema.sql`
   - `supabase/fix-register.sql`
   - `supabase/rtdb-mirror.sql`
   - bucket `media` public + `supabase/storage.sql`
2. Key sudah di `js/config.js`
3. Deploy ke Vercel

## Bot
`bot-termux.js` — jalankan di Termux.
